# Muslim Chat Bots

日本語で提供する事業者向けウェブサイトです。React と TypeScript の画面を Vite で配信し、Express の API が問い合わせを受け付けて SMTP 経由でメールを送信します。

## フォルダー構成

- `src/` — React 画面、表示文言、ページ情報、スタイル
- `server/` — Express API、入力検証、問い合わせテスト
- `public/` — 公開する画像、動画、ホスティング設定
- `scripts/` — 静的ページの生成
- `background/`、`video/` — 元画像・動画素材
- `dist/` — ビルド成果物。生成物のため Git 管理外

## 開発と確認

依存パッケージをインストールしたあと、フロントエンドと API を別々のターミナルで起動します。

```sh
npm install
npm run dev
npm run dev:server
```

フロントエンドの開発サーバーは `/api` へのリクエストをローカルの API に転送します。

```sh
npm run test:contact
npm run build
npm run preview
```

ビルドでは型検査、Vite による生成、日本語ページの事前生成を行います。静的ページは `dist/` に出力されます。Express API は静的サイトとは別に実行・配備し、配備先で `/api` を適切に接続してください。

## 環境変数と機密情報

`.env.example` を参考に、開発環境用の `.env` をプロジェクト直下に用意します。`.env` や認証情報を含むファイルは Git 管理外です。`.env.example` には秘密情報を記載しないでください。

`SMTP_USER`、`SMTP_PASS`、メール送信先などのメール設定は Express API の実行環境にだけ設定します。これらを `VITE_` で始まる名前にしたり、フロントエンドのソースへ記載したりしないでください。`VITE_` で始まる値はブラウザーへ公開されます。公開 URL など秘密ではない設定だけに使用してください。

本番環境では、環境変数を配備先の秘密情報管理機能で登録します。メール送信には証明書検証を有効にした TLS 接続を使用します。

Vite の開発サーバーは環境ファイル、秘密鍵、Git メタデータ、ローカルの npm 設定ファイルを配信しません。本番の静的配信対象は `dist/` のみです。
